# BetterMaps

Orte finden, bei denen auch die Umgebung passt – z. B. ein Restaurant in Rosenheim mit Spielplatz und E-Ladesäule in 500 m Umkreis.

- Daten: OpenStreetMap (Nominatim, Overpass), kein Schlüssel nötig
- Karte: OpenStreetMap, optional Google Maps mit eigenem API-Schlüssel (wird nur im Browser gespeichert)
- `python3 build.py` erzeugt `bettermaps-mobil.html` (alles in einer Datei)
